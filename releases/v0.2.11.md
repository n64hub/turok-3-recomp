An update to Turok 3: Recompiled, for Windows and Linux: the weapon wheel picks the weapon the stick points at.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**What's new:**

- **Weapon wheel:** pushing the stick (or the arrow keys) towards a weapon on the wheel picks that weapon. Up and down were swapped there: the stick is turned over for looking, so that pushing it up looks up, and the wheel read it turned over too. Looking is as before.

**Windows:** unzip `Turok3Recompiled-v0.2.11-windows-x64.zip` and run `Turok3Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `Turok3Recompiled-v0.2.11-linux-x64.tar.gz` and run `Turok3Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). You need your own ROM of the USA release (a big-endian `.z64` of 32 MiB, SHA-1 `a2e0a28dc0d3a48c7c02cb9e4c4b38fe04b2d436`): pick it with **Load ROM**, then **Start Game**.

**Not checked yet:** the wheel itself in play (the change is the one Turok 2: Recompiled v0.2.22 made to the same code, where it was played), the levels past the first, a whole playthrough (reports are welcome on the [issues page](https://github.com/n64hub/turok-3-recomp/issues)), and the Linux build on a GPU other than NVIDIA's.

The same game plays in a browser at [n64hub.com/turok-3](https://n64hub.com/turok-3/).
