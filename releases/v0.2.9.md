An update to Turok 3: Recompiled, for Windows and Linux: the stick and the keys reach the picture sooner, anti-aliasing goes up to 8X, and more controllers are mapped.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**What's new:**

- **Less input lag:** each frame waited most of its time with the pad it read already old. The game now starts each frame just in time for its turn on the screen and shows it as soon as it is drawn. Measured from a press of the stick or a key to the picture changing, the median is about 85 ms instead of 135 ms (of which about 70 ms is the measurement's own capture of the window). Where the game runs slower than 30 frames a second (the cutscenes), frames start and show as before.
- **MS Anti-Aliasing** goes up to **8X**, where the GPU can take it (greyed out where it can't). 2X stays the default.
- **More controllers:** the controller database is refreshed from SDL's, which maps 32 more pads and updates 17.

**Windows:** unzip `Turok3Recompiled-v0.2.9-windows-x64.zip` and run `Turok3Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `Turok3Recompiled-v0.2.9-linux-x64.tar.gz` and run `Turok3Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). You need your own ROM of the USA release (a big-endian `.z64` of 32 MiB, SHA-1 `a2e0a28dc0d3a48c7c02cb9e4c4b38fe04b2d436`): pick it with **Load ROM**, then **Start Game**.

**Not checked yet:** the change on Windows (it was measured on the Linux build), the levels past the Breach, Joseph's path, a whole Deathmatch, long play sessions, and the Linux build on a GPU (it has been booted on Mesa's software Vulkan only). Reports are welcome on the [issues page](https://github.com/n64hub/turok-3-recomp/issues), saying where you were and what you did.

The same game plays in a browser at [n64hub.com/turok-3](https://n64hub.com/turok-3/), with the same change (anti-aliasing isn't available in a browser).
