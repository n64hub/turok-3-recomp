An update to Turok 3: Recompiled, for Windows and Linux.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**What's new:** up looks up: moving the mouse up, the up arrow and the right stick pushed up now look up; in v0.2.0 they looked down, since the game looks down with its stick pushed up, as a plane's stick does.

**Windows:** unzip `Turok3Recompiled-v0.2.1-windows-x64.zip` and run `Turok3Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `Turok3Recompiled-v0.2.1-linux-x64.tar.gz` and run `Turok3Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). You need your own ROM of the USA release (a big-endian `.z64` of 32 MiB, SHA-1 `a2e0a28dc0d3a48c7c02cb9e4c4b38fe04b2d436`): pick it with **Load ROM**, then **Start Game**.

**Not checked yet:** the levels past the Breach, Joseph's path, Deathmatch, saving to and loading from the Controller Pak, long play sessions, and the Linux build on a GPU (it has been booted on Mesa's software Vulkan only). Reports are welcome on the [issues page](https://github.com/n64hub/turok-3-recomp/issues), saying where you were and what you did.

The same game plays in a browser at [n64hub.com/turok-3](https://n64hub.com/turok-3/).
