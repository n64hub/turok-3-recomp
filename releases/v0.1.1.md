An update to Turok 3: Recompiled, for Windows and Linux.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**What's new:**

- Widescreen: in a window wider than 4:3 the level reaches the window's edges and the HUD sits at its sides (Aspect Ratio, on the Graphics settings; Original keeps the 4:3 picture)
- The desktop build shows the game at the window's resolution: v0.1.0 showed it at the console's, scaled up, whatever the Resolution setting. The video mode the game builds for itself points at the very start of its framebuffer, where the console's own modes point one row in, so the renderer never found the frame the game drew there; now it does

**Windows:** unzip `Turok3Recompiled-v0.1.1-windows-x64.zip` and run `Turok3Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `Turok3Recompiled-v0.1.1-linux-x64.tar.gz` and run `Turok3Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). You need your own ROM of the USA release (a big-endian `.z64` of 32 MiB, SHA-1 `a2e0a28dc0d3a48c7c02cb9e4c4b38fe04b2d436`): pick it with **Load ROM**, then **Start Game**.

**Not checked yet:** the levels past the Breach, Joseph's path, Deathmatch, saving to and loading from the Controller Pak, long play sessions, and the Linux build on a GPU (it has been booted on Mesa's software Vulkan only). Smooth motion and mouse look, which Turok 2: Recompiled has, are still to come. Reports are welcome on the [issues page](https://github.com/n64hub/turok-3-recomp/issues), saying where you were and what you did.

The same game plays in a browser at [n64hub.com/turok-3](https://n64hub.com/turok-3/).
