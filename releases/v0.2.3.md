An update to Turok 3: Recompiled, for Windows and Linux: the mouse turns the view directly, as in a PC shooter, and the menus' cursor goes the way it's pushed.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**What's new:**

- The mouse turns the view directly, as in a PC shooter: a small movement is no longer lost in the stick's dead zone, the view turns by as much as the mouse moves, and looking up or down stays where the mouse put it instead of springing back level. Mouse Sensitivity sets how far it turns.
- In the menus the up arrow (and the right stick pushed up) moves the cursor up and the down arrow down: they went the other way.

**Windows:** unzip `Turok3Recompiled-v0.2.3-windows-x64.zip` and run `Turok3Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `Turok3Recompiled-v0.2.3-linux-x64.tar.gz` and run `Turok3Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). You need your own ROM of the USA release (a big-endian `.z64` of 32 MiB, SHA-1 `a2e0a28dc0d3a48c7c02cb9e4c4b38fe04b2d436`): pick it with **Load ROM**, then **Start Game**.

**Not checked yet:** the levels past the Breach, Joseph's path, Deathmatch, saving to and loading from the Controller Pak, long play sessions, and the Linux build on a GPU (it has been booted on Mesa's software Vulkan only). Reports are welcome on the [issues page](https://github.com/n64hub/turok-3-recomp/issues), saying where you were and what you did.

The same game plays in a browser at [n64hub.com/turok-3](https://n64hub.com/turok-3/).
