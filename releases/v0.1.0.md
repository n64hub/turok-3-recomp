The first release of Turok 3: Recompiled for Windows and Linux: a native PC port of the N64 *Turok 3: Shadow of Oblivion* made by static recompilation. It is not an emulator and contains no game data: you need your own ROM of the USA release (a big-endian `.z64` of 32 MiB, SHA-1 `a2e0a28dc0d3a48c7c02cb9e4c4b38fe04b2d436`). Other regions are not supported.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `Turok3Recompiled-v0.1.0-windows-x64.zip` and run `Turok3Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `Turok3Recompiled-v0.1.0-linux-x64.tar.gz` and run `Turok3Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). Pick your ROM with **Load ROM**, then **Start Game**: the ROM is stored, so the next start goes straight to the game.

**What works:** the legal screen, the logos, the title and the menus; a new game's opening scene, the character choice and Danielle's scene into the first level, the Breach: walking, turning and firing, and the pause menu. Sound (the game's own audio code, recompiled), and keyboard and gamepad input.

**Enhancements:**

- High resolution at the window's size, with anti-aliasing
- Keyboard and gamepad controls, rebindable

**Not checked yet:** the levels past the Breach, Joseph's path, Deathmatch, saving to and loading from the Controller Pak, long play sessions, and the Linux build on a GPU (it has been booted on Mesa's software Vulkan only). Smooth motion, widescreen and mouse look, which Turok 2: Recompiled has, are still to come. Expect the odd thing drawn wrong or a spot that hangs; reports are welcome on the [issues page](https://github.com/n64hub/turok-3-recomp/issues), saying where you were and what you did.

The same game plays in a browser at [n64hub.com/turok-3](https://n64hub.com/turok-3/). The [README](https://github.com/n64hub/turok-3-recomp#readme) has how to build it yourself.
