An update to Turok 3: Recompiled, for Windows and Linux.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**What's new:**

- Mouse look: the mouse turns and looks, and its left button fires. It is on from the first start (General, Mouse Sensitivity, 50%; 0 turns it off and leaves the cursor free); if you played v0.1.0 or v0.1.1, your saved settings have it at 0, so turn it up there
- A shooter's controls, as Turok 2: Recompiled has them: WASD to walk and strafe, the mouse or the arrow keys to look, Space to jump, Q and E to change weapon, Tab for the map; on a controller, the two sticks, the right trigger to fire and the bottom face button or the left trigger to jump. All rebindable on the Controls tab
- Smooth motion: RT64 draws the frames between the game's own at the display's rate (the Graphics tab's Framerate; Original shows the game's own)

**Windows:** unzip `Turok3Recompiled-v0.2.0-windows-x64.zip` and run `Turok3Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `Turok3Recompiled-v0.2.0-linux-x64.tar.gz` and run `Turok3Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). You need your own ROM of the USA release (a big-endian `.z64` of 32 MiB, SHA-1 `a2e0a28dc0d3a48c7c02cb9e4c4b38fe04b2d436`): pick it with **Load ROM**, then **Start Game**.

**Not checked yet:** the levels past the Breach, Joseph's path, Deathmatch, saving to and loading from the Controller Pak, long play sessions, and the Linux build on a GPU (it has been booted on Mesa's software Vulkan only). Reports are welcome on the [issues page](https://github.com/n64hub/turok-3-recomp/issues), saying where you were and what you did.

The same game plays in a browser at [n64hub.com/turok-3](https://n64hub.com/turok-3/).
