An update to Turok 3: Recompiled, for Windows and Linux: its Controller Pak is now the one the recomps' shared runtime has, and the runtime and renderer are updated. Saves made by earlier versions load as before.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**What's new:**

- **Controller Pak:** the game's pak is now the one the web support's runtime has for every recomp, in place of a copy of its own. It is the same file (`saves/controllerpak_1.mpk`), so saves made by earlier versions load as before: a save made with v0.2.9 was loaded and saved over with this version.
- The renderer and runtime are N64Recomp-browser v0.257.0's (from v0.235.0), with the fixes made since for every recomp.

**Windows:** unzip `Turok3Recompiled-v0.2.10-windows-x64.zip` and run `Turok3Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `Turok3Recompiled-v0.2.10-linux-x64.tar.gz` and run `Turok3Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). You need your own ROM of the USA release (a big-endian `.z64` of 32 MiB, SHA-1 `a2e0a28dc0d3a48c7c02cb9e4c4b38fe04b2d436`): pick it with **Load ROM**, then **Start Game**.

**Not checked yet:** the change on Windows (the save was made and loaded on the Linux build), the levels past the first, a whole playthrough (reports are welcome on the [issues page](https://github.com/n64hub/turok-3-recomp/issues)), and the Linux build on a GPU other than NVIDIA's.

The same game plays in a browser at [n64hub.com/turok-3](https://n64hub.com/turok-3/).
