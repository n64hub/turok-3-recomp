# The RT64 shaders the web page builds: one shader description a line, other mode L and H, color combiner L and H,
# flags, in hex. RT64 specializes each one's WGSL when the page is built and builds them with the game waiting: those
# above the first "section" line before the game starts, and a level's section when the level first draws with its
# shaders, so that nothing draws with the ubershader, which integrated graphics can't afford (N64Recomp-browser's
# docs/porting.md, Prebuilt shader lists).
#
# Recorded by code, not by playing: node lib/N64Recomp-browser/tools/record_shaders.mjs tools/shader_plan.json
# build/web roms/turok3.us.z64 src/rt64_shaders.txt (its header says how), on tools/build_web.sh's page. Section 0 is
# the launcher, the boot (the legal screen, the logos, the title), the main menu, New Game's difficulty, the Rumble
# Pak notice, the opening scene and the character choice, reached with Start (Enter) held 400 ms every 5 s, as the
# game reads its pad a few times a second while the page has no list. The plan's waits are the browser's time: nothing
# tells it where the game is. Then the Breach, the first level, reached by choosing Danielle and skipping her scene,
# walked (the C buttons), turned (the stick) and fired in for 25 s. The plan's last section, pause, goes into section
# 0: the pause menu, which comes up in any level, and its Save Game screen. Not recorded: the rest of the Breach, the
# other levels, Joseph and Deathmatch. The Breach section's last line is one the regular play (tools/play_plan.json, 70 s
# there) missed, added by hand. Flags follow settings (filtering, HDR, MSAA, upscaling), so a change to one of those
# defaults means recording again.
